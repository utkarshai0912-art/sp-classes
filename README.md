## 🏛️ About S.P. Classes

S.P. Classes provides structured academic guidance and focused learning for students in Shivpuri, Pachaoli, and the surrounding Etawah region. The website is designed to convert local search visitors into enquiries, phone consultations, and admission discussions.

## 🚀 Key Features

- **Strict Truth-in-Advertising (Zero Fake Information)**: All unverified fields (phone numbers, WhatsApp, opening hours, specific course batch schedules) are mapped to central configurable placeholders.
- **Conversion-Centric Architecture**:
  - Hero with high-impact CTAs (*"Enquire About Classes"*, *"Get Directions"*).
  - Universal Admission & Batch Enquiry modal with live client-side validation and feedback states.
  - Mobile Sticky Bottom Action Bar with 48px touch targets: `📞 Call` | `💬 WhatsApp` | `📍 Directions` | `📝 Enquire`.
- **Pages Included**:
  - `Home`: Full structured layout following local academic discovery journey.
  - `Classes & Courses`: Category-filtered catalogue with direct batch enquiry actions.
  - `About`: Educational philosophy and transparent leadership placeholders.
  - `Inside S.P. Classes (Gallery)`: Responsive photography showcase with a keyboard-accessible Lightbox viewer.
  - `Reviews & Feedback`: Verified-only Google Reviews policy container.
  - `FAQ`: Accessible accordion with instant search.
  - `Contact & Location`: Interactive contact form, embedded map, and direction links.
- **Live Owner Configuration Drawer**: Test replacing placeholder values live in the browser and export configuration JSON.
- **SEO & Schema.org**: Verified `EducationalOrganization` JSON-LD structured data embedded in `<head>`.
- **Accessibility & Performance**: WCAG contrast compliant, keyboard navigable, and `prefers-reduced-motion` enabled.

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/utkarshai0912-art/sp-classes.git

# Navigate to project directory
cd sp-classes

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
